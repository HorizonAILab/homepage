# Tingjin Luo — Homepage

解压后打开 `index.html`。在主页按 **N** 进入导航，按 **P** 打开 Publication。

- `navigate.html`：BlueRevision 与 Publication 的入口。
- `publications.html`：灰蓝玻璃版论文页，多选按交集筛选。
- `blue-revision/index.html`：完整 BlueRevision；所有处理代码已内嵌，可直接打开、离线处理 TEX / ZIP，不编译。
- `favicon.ico`：主页使用提供的原版图标；`icons/` 包含其他页面的 SVG / PNG 图标。

托管时上传整个目录并保留相对路径。论文页的在线字体和外部论文链接需要网络，字体不可用时使用系统字体。

## Google Scholar 指标

只需更新 `scholar-metrics.js` 顶部的 `citations`、`hIndex`、`i10Index` 和 `updatedAt`；取 Scholar 的 **All** 栏，日期填写实际核对日期。当前数值沿用 2026-10-08 的原有快照，本次没有获取到实时个人页。HTML 不再重复保存数值。部署时一同上传更新的 JS，确保托管服务未强制长期缓存该文件。

首次访问直接显示数值；同一浏览器再次访问时，仅上涨的指标从上次值递增到新值。持平或下降直接显示，减少动态效果偏好会停用动画。记录保存在访客本机，不跟踪身份；清除存储或更换设备会视为首次访问。

## BlueRevision 本次更新

- 先依据主文件载入关系、章节标签/标题和正文确认章节身份，处理插章、改名与重编号；对照预览显示旧路径与新路径。
- 差异对齐采用位并行 LCS、Hirschberg 精确重建及段落—行—句子的精确复用；移动段落不扩大标蓝，新增重复副本仍保留新增计数。
- 支持教材导读、定理与正文盒子、伪代码、表格单元格、图题、常见公式及可静态确认的数学别名。
- 正常语法、路径、列格式、排版参数等不再作为待核对项。绘图、宏定义、原样代码和无法安全处理的结构保留核对提示；报告同时保留完整跳过明细。
- 左侧显示实际写入的标蓝数量；核对项按相邻位置合并并显示行号范围，避免一条正文被语法边界拆成大量提醒。
- Worker 只接收 TEX 源码；图片和其他资源留在原线程，导出使用新版原始字节。编译辅助及系统文件继续按原规则忽略。

以两份完整教材实测；书稿素材不包含在网站包中。删除内容不标蓝。本工具不执行 TeX，也不判断宏展开后的 PDF 效果。

## 主页展示

邮箱使用与手机一致的系统字体。Selected publications 采用原生横向滑动，桌面一次显示两篇半，使用小缩略图、完整标题与作者，以及一句话介绍；文字自然换行，不截断、不以省略号隐藏。点击配图打开原图。手机保持文字简版。滑到桌面末尾仍铺满内容，支持前后按钮及方向键、Home、End。论文数据仍集中在 `index.html` 的 `homepage-paper-data` 中。无需 Swiper。

桌面滚动仅添加轻微入场与照片视差，并响应系统减少动态效果设置。Publication 的论文行取消分隔线，悬停或键盘聚焦显示与筛选项一致的浅蓝色圆角底，无阴影。
